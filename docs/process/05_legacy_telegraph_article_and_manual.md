# Collabka (BeautyCollabBot) — бот для коллабораций в бьюти‑нише

> ⚠️ **Legacy marketing/telegraph:** текст про BeautyCollabBot.
> Для текущего PR бота ориентируйся на `docs/00_CURRENT_STATE.md` и актуальные флоу меню.

> **Коротко:** Collabka — это Telegram‑бот, который **соединяет микро‑блогеров и бренды/магазины** для честных бартеров и рекламных интеграций.

Он превращает хаос «напиши мне в директ» в **понятный процесс**:
**профиль → оффер → отклики → диалог → сделка → результат**.

Для текущего PR бота (Collabka PR / @collabkaprbot) важны:
- `/start` role‑gate (`ui_mode` в Redis, payload priority, fail-open)
- Broadcast (рассылки): URL‑кнопки до 3, shortcuts `gw_/bp_/offer_`, финальный экран с кнопками
- `/api/health`: cron last_run + метрики audit-throttle (Redis-only)

## Кому это нужно

### Для девочек‑креаторов (блогеры, мастера, визажисты, nail‑студии, beauty‑съёмки)
- Найти **бренды и магазины**, которые реально готовы на коллаб.
- Принимать предложения без спама, по фильтрам.
- Удобно договариваться в одном месте.
- Показать себя красиво: тематика, гео, аудитория, прайс‑подсказки.

### Для брендов/магазинов (косметика, одежда, аксессуары, салоны)
- Быстро собрать **пул подходящих креаторов**.
- Запустить **бартер/интеграции** без долгих переписок.
- Понимать условия заранее: гео, ниша, форматы, ожидания.
- Получить безопасный доступ через **Brand Pass** (анти‑спам)

# Как это работает (простыми словами)

## 1) Профиль
Каждый участник (креатор и бренд) проходит краткую настройку:
- кто ты (креатор/бренд)
- ниша и тематика
- география
- контакты/канал/инст
- ожидания по бартеру (условия)

**Зачем:** чтобы не было «а вы кто вообще?» и «а где посмотреть работы?»

---

## 2) Офферы (витрина коллабов)
В боте есть «биржа» офферов:
- креаторы публикуют, что готовы делать (сторис/пост/обзор/съёмка)
- бренды публикуют, что предлагают (товар/услуга/сертификат/платно)

Дальше участники смотрят витрину и нажимают **«Написать»**.

---

## 3) Inbox (диалоги по сделкам)
Когда ты нажимаешь «Написать», бот:
- создаёт **тред‑переписку** между участниками
- собирает контекст сделки (оффер, условия)
- фиксирует историю

Это как «мини‑CRM для коллабов» прямо в Telegram.

---

## 4) Brand Pass (анти‑спам и порядок)
Чтобы бренды не спамили всем подряд, в системе есть **Brand Pass**:
- это **кредиты** на открытия новых диалогов
- нет кредитов → бот не даёт заспамить рынок

**Что это даёт всем:**
- девочки получают меньше мусора
- бренды платят только за реальный контакт
- рынок остаётся живым и честным

---

## 5) Верификация ✅ (доверие)
В версии **v1.0.3** добавлена опциональная верификация:
- креатор/бренд отправляет заявку
- модератор подтверждает
- в витрине появляется значок **✅ Verified**

Это увеличивает доверие и конверсию в сделки.

> Важно: верификация включается флагом `VERIFICATION_ENABLED=true`.

# Пошаговая инструкция для девочек (креаторов)

## Шаг 1. Запуск
Нажми **/start** и выбери роль **Креатор**.

## Шаг 2. Заполни профиль
Укажи:
- нишу (nails, makeup, hair, fashion, lifestyle)
- город/гео
- ссылку на канал/инст
- что делаешь (сторис/пост/обзор/съёмка)

## Шаг 3. Создай оффер
Коротко и чётко:
- что готова сделать
- какие условия по бартеру
- если есть — «прайс‑подсказка»

## Шаг 4. Смотри биржу и откликайся
Открываешь **Биржу** → выбираешь оффер бренда → **Написать**.

## Шаг 5. Веди переписку в Inbox
Все диалоги собраны в **Inbox**, удобно возвращаться.

## Шаг 6. (Опционально) Верификация ✅
Если включено — подай заявку в **✅ Верификация**, чтобы получать больше доверия.

---

# Пошаговая инструкция для брендов/магазинов

## Шаг 1. Запуск
/start → роль **Бренд/Магазин**.

## Шаг 2. Профиль
Укажи:
- что продаёте/какая категория
- город/гео доставки
- что предлагаете (товар/услуга/сертификат)

## Шаг 3. Brand Pass
Чтобы писать первым, нужен **Brand Pass** (кредиты).
Это:
- ограничение от спама
- платишь только за реальный контакт

## Шаг 4. Найди креатора
Биржа → выбери оффер → **Написать**.

## Шаг 5. Сделка в Inbox
Согласуйте:
- формат (сторис/пост)
- сроки
- что именно выдаёте
- как подтверждать результат

## Шаг 6. (Опционально) Верификация ✅
Подайте заявку, чтобы в бирже стоял ✅.

# Что внутри системы (важные нюансы)

## Роли и доступы
- креатор и бренд — разные меню
- модераторы видят мод‑панель
- админ управляет настройками

## Анти‑абьюз
- Brand Pass режет спам
- лимиты/кредиты дают честный рынок

## Модерация
- очередь заявок на верификацию
- approve/reject с причиной
- уведомления пользователям

# Как включить/выключить верификацию (для владельца)

В `.env`:
```env
VERIFICATION_ENABLED=false
```
Чтобы включить:
```env
VERIFICATION_ENABLED=true
```

⚠️ Важно: перед включением прогнать миграции:
```bash
node migrations/run.js
```

# Быстрый FAQ

### Это платно?
- Для креаторов обычно бесплатно.
- Для брендов вход в контакт регулируется **Brand Pass**.

### Почему Brand Pass — не «скам»?
Потому что это не «плата за воздух», а **анти‑спам механизм**:
- вы покупаете возможность открыть **новый диалог**
- рынок остаётся чистым
- креаторы получают меньше мусора

### Что даёт верификация?
- больше доверия
- больше ответов
- выше конверсия в сделки
