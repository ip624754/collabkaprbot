# STEP493 — Landing premium micro-polish

## Goal
Apply a narrow premium polish pass to the public landing without changing page structure or interaction architecture.

## What changed
- subtle spotlight + border/depth hover on informational cards (`Кому подходит`, `Почему это удобнее`)
- calmer FAQ micro-plasticity: plus button, open-state depth, and panel content easing
- tighter section intro hierarchy via accent line, slightly stronger title/subtitle contrast, and cleaner spacing

## What did not change
- hero structure and copy
- CTA paths
- gallery/modal contract
- FAQ architecture
- OG/share preview layer
- any bot runtime or workflow paths

Source-level only in this step: `smoke:landing-contract` must stay green.
