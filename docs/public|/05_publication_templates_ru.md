# 05 — Шаблоны публикаций (посты / закреп / Telegraph)

> Бот: **@collabkaprbot**

Ниже — готовые тексты, которые можно брать почти без правок. Пиши под свою аудиторию: где‑то “лайтово”, где‑то “строже”.

---

## A) Очень коротко (30–40 секунд)

**Collabka PR Bot — бот для коллабораций брендов и креаторов в Telegram.**

✅ Витрина креатора (workspace) по ссылке
✅ Заявки от брендов + Inbox
✅ Офферы (UGC/бартер/интеграции)
✅ (Опционально) Розыгрыши и рассылки

Старт: открой **@collabkaprbot** → `/start` → выбери режим **Креатор** или **Бренд**.

---

## B) Пост для креаторов

Креатор, хочешь меньше спама и больше нормальных запросов?

В Collabka PR Bot:
1) `/start` → **Креатор**
2) подключи канал/проект (workspace)
3) заполни профиль и сделай оффер

Бренды пишут через Inbox, статусы помогают не терять сделки.

---

## C) Пост для брендов/агентств

Бренд/агентство: нужны креаторы без хаоса и “поиска в директе”?

Collabka PR Bot:
- открываешь витрину креатора по ссылке
- отправляешь запрос
- ведёшь сделку в Inbox

Есть защита от спама (план/кредиты) — поэтому входящие у креаторов чище.

---

## D) Закреп (пин) в канале

**Collabka PR Bot** — быстрые коллаборации в Telegram.

Креаторы: витрина + офферы + входящие запросы.
Бренды: запросы + сделки + статусы.

Старт: открой **@collabkaprbot** → `/start`.

---

## E) “План/кредиты — зачем?” (коротко)

Чтобы в рынке не было спама.
Кредиты — это “стоимость намерения”: бренд тратит их на открытие контактов/первый контакт, а креаторы получают меньше мусора.
(Публичное объяснение “почему так”: `docs/public/10_brand_plan_explainer_ru.md`.)
