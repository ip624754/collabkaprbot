Документ описывает формат хранения и UX заметок команды по заявкам брендов (`brand_leads`).


## Назначение
**Curator Notes** — внутренние заметки, прикреплённые к заявке бренда (`brand_leads`). Используются owner/admin/curator для:
- фиксации контекста и next steps
- быстрых отметок (brief/budget/format/follow-up/spam/urgent)
- сохранения истории внутри команды

> Важно: заметки **не видны бренду**, только команде.

---

## Хранилище
`brand_leads.meta.curator_notes` — JSON-массив.

Поддерживаются **две формы** (backward compatible):

### v1 (legacy)
Элемент массива — строка:
```json
"Позвонить завтра"
```

### v2 (актуальная)
Элемент массива — объект:
```json
{
  "by": 12345,
  "at": "2026-02-09T12:34:56.789Z",
  "text": "⏳ Ждём бриф #brief",
  "role": "curator",
  "tags": ["brief"]
}
```

Поля:
- `by` *(number)* — user_id автора (из БД пользователя бота)
- `at` *(timestamp/string)* — время добавления (server time)
- `text` *(string)* — текст заметки (обрезается до 1200 символов на уровне DB helper)
- `role` *(string|null)* — `owner|admin|curator` (опционально)
- `tags` *(string[])* — список тегов (0..8)

---

## Нормализация (UI)
В UI заметки приводятся к единому виду:
- если заметка — строка, отображается как `id:?` и без роли (legacy)
- если заметка — объект, используется `by/at/text/role/tags`
- если `tags` отсутствуют, UI извлекает их из текста по `#tag`

---

## Теги
### Правила
- Теги пишутся прямо в тексте в формате `#tag`
- Допустимые символы: латиница/цифры/`_`/кириллица
- Длина тега: 2..24
- Уникальные теги, максимум **8** на заметку
- В хранилище тег сохраняется **без** `#` (например: `"brief"`)

### Авто-извлечение
Для ручных заметок теги извлекаются из текста автоматически и сохраняются в `meta`.

## Шаблоны заметок
В UI есть быстрые шаблоны (быстрая кнопка → мгновенно сохраняет заметку):

| Key | Label | Text | Tags |
|---|---|---|---|
| `wb` | ⏳ Бриф | `⏳ Ждём бриф #brief` | `brief` |
| `bd` | 💰 Бюджет | `💰 Уточнить бюджет #price` | `price` |
| `fm` | 📌 Формат | `📌 Уточнить формат/площадку #format` | `format` |
| `fu` | 🔁 Follow-up | `🔁 Сделать follow-up #followup` | `followup` |
| `ur` | ⚡ Срочно | `⚡ Срочно проверить #urgent` | `urgent` |
| `sp` | 🚫 Спам | `🚫 Похоже на спам #spam` | `spam` |

## UX Flow
### 1) Lead View (карточка заявки)
- Показывает последние 3 заметки + теги (если есть)
- Кнопка `🗒️ Заметки (N)` открывает viewer
- Кнопка `📝 Добавить заметку` открывает меню выбора (шаблон/вручную)

### 2) Notes Viewer (просмотр всех заметок)
- Пагинация 5/страница
- Заметки в обратном порядке (новые сверху)
- Кнопка `📝 + Заметка` открывает меню добавления
- При возврате из добавления заметки — возвращаемся **туда же**, откуда пришли (viewer или lead view)

### 3) Add Note Menu
- Сетка кнопок-шаблонов + кнопка `✍️ Ввести вручную`
- Подсказка по тегам
- `⬅️ Назад` возвращает в viewer или lead view (с учётом исходного контекста)

---

## Ограничения
- Ручная заметка: до 800 символов (UI)
- DB helper дополнительно обрезает до 1200 (страховка)
- Tags: до 8 (хранение), до 6 отображение в карточке (UI)
