# 22 — OFFER WIZARD — SPEC v2 — 2026-02-20

**Цель:** убрать тупики в визарде оффера: на последнем шаге всегда есть ясные действия.

---

## 1) Поведение (без регрессий)

### Шаг «перед финалом»
- `➡️ Далее` присутствует всегда (не только через Skip), чтобы не было ощущения «застрял».

### Финальный шаг («Текст + Публикация»)
Показываем явные действия:
- `✍️ Написать текст` — ForceReply для ввода текста
- `📄 Шаблон` — вставка шаблона + ForceReply
- `✅ Опубликовать` — активно только если есть текст/контент

---

## 2) После публикации (финальный экран)

После publish показываем быстрые действия:
- `👀 Посмотреть`
- `⬆️ Поднять` (если доступно по плану)
- `🔗 Поделиться` (deep-link)
- `🗄 В архив`

**Инвариант:** не добавлять лишних DB‑операций в рендер финального экрана; использовать уже известные данные драфта/оффера.
