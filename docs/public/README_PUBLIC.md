# PUBLIC DOCS — Collabka PR (@collabkaprbot)

Это публичный пакет материалов о **Collabka PR** — системе для коллабораций брендов и креаторов внутри Telegram.

Основной интерфейс доступа — Telegram-бот, но сам продукт — это не просто чат-бот, а рабочая система: витрины, офферы, заявки, Brand Inbox, статусы сделок и управляемый creator pipeline.

Цель: чтобы можно было **быстро и красиво объяснить**, что делает система, *кому она нужна* и *как через неё работать* — без внутренней техдокументации.

---

## Как выбрать нужный документ

### Если нужен **короткий пост / закреп / описание**
- `05_publication_templates_ru.md` — готовые тексты (посты, закреп, короткие блоки)
- `07_press_kit_ru.md` — формулировки для лендинга/каталогов/партнёрских анонсов

### Если нужен **one‑pager (понятно всем)**
- `00_product_overview_ru.md` — что это за система и зачем она нужна

### Если нужен **подробный гайд “что нажимать”**
- Креаторам: `01_for_creators_ru.md`
- Брендам/агентствам: `02_for_brands_ru.md`

### Если нужен **FAQ**
- `03_faq_ru.md`

### Если нужна **большая статья под Telegraph/Medium**
- `06_telegraph_article_ru.md` — статья “под ключ”

### Если нужен **тех‑обзор для партнёров**
- `04_tech_overview_ru.md` — без лишней инженерии, но честно

### Если нужно **объяснение приватности/безопасности**
- `08_privacy_security_ru.md`

### Если нужно **проиллюстрировать сценарии и кейсы**
- `09_use_cases_ru.md`

### Если нужно **просто объяснить анти‑спам (план/кредиты) человеческим языком**
- `10_brand_plan_explainer_ru.md`

### Если нужно объяснить **ленту/каталог и discovery**
- `11_feeds_and_discovery_ru.md`

## Как говорить о продукте правильно

Базовая формулировка:

**Collabka PR — это система управления коллаборациями брендов и креаторов внутри Telegram.**

Уточнение:

**Telegram-бот — это интерфейс доступа к витринам, офферам, заявкам, Brand Inbox и статусам сделок.**

Простым языком:

**Collabka PR превращает хаос «напиши мне в директ» в понятный рабочий процесс.**
