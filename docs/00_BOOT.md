# 00 — BOOT (якорь контекста)

1) Мы в **serverless** (Vercel) → никаких “долгих” процессов, всё пакетами.
2) **Neon** экономим: не добавляй лишние DB-запросы в горячие UI-рендеры (меню/кнопки).
3) Любая “тяжёлая” операция: **SQL-side**, а не вытягивание 10–50k строк в Node.
4) В кронах всегда: **Redis lock** (между инстансами) + где критично **PG advisory lock**.
5) Любое изменение статуса — **атомарно** (guard по полям типа `winners_drawn_at`).
6) Winner selection — **детерминированно** (seed+hash), воспроизводимо, без `random()` в Node.
7) Ошибка → лучше “мягко остановиться” (runtime guard), чем получить hard-kill Vercel.
8) Миграции только через **migrations/run.js** (exactly-once, checksum), без ручных ALTER в проде.
9) Каждый патч: **маленький**, обратимый, артефакты: **FULL zip + Hotfix zip + git-apply patch** + список файлов + QA чеклист.
10) UX принцип: **кнопка видна**, доступ гейтится внутри фичи, CTA ведёт туда, где решить проблему.
11) Держим стиль **Jobs/Vitalik/Woz**: просто, прозрачно, детерминированно, без магии.
