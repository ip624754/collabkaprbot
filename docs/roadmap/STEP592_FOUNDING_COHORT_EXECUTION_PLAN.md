# STEP592 — Founding Cohort and Marketplace Liquidity

## North-star

```text
Reviewed creator supply → active offers → qualified brand demand
```

## Phase A — Workspace acceptance

- production health remains `ready / GO`;
- Users page renders cohort workspace on desktop/mobile;
- founder-only writes return 200 for valid session and 403 for operator session;
- persisted config and member survive refresh;
- no Telegram/payment/publish side effects.

## Phase B — Cohort formation

- name one cohort owner;
- set 3–7 day follow-up cadence and next review date;
- add up to 10–15 real creators as candidates;
- classify blockers explicitly;
- remove non-creators and stale/no-channel candidates.

## Phase C — Launch readiness

- review profile, contact and terms;
- complete one onboarding canary and keep its PASS timestamp within the 14-day freshness window;
- create or activate at least 5 real offers through the normal creator product flow;
- verify cohort progress in admin after refresh.

## Exit

- 10+ launch-ready creators;
- 5+ active offers;
- zero blocker defects;
- onboarding canary PASS no older than 14 days;
- named owner and configured future next review.
