## Вариант для «Рецензии» (рекомендуется)
Сделайте строгую рецензию проекта как Staff Backend + SRE + Security:
- 3–5 P0/P1 рисков, которые реально могут уронить прод или деньги.
- 5–10 самых вероятных регрессий (hot paths, монетизация, inbox gate, контакты, broadcast, QStash).
- Где в доках/коде противоречия (docs ↔ code).
- 3 “quick wins” фикса без расширения поверхности (surgical, zero regressions).
Говорите только фактами из загруженных файлов. Если данных нет — так и скажите.

## Вариант для «Краткого пересказа»
Коротко: что это за продукт, кто пользователи, где paywall, где самые рисковые места, что проверять руками после деплоя (10 пунктов).

## Вариант для «Подробного анализа»
Пройдитесь системно: entrypoints → action keys → paywalls → Redis keys → DB critical model → деградации → top bypass вектора.

## Вариант для «Дебатов»
