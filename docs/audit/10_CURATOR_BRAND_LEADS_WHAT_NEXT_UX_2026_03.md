# 10 — Curator ↔ Brand Leads “What next” UX audit — 2026-03

Цель: привести кураторский разбор **заявок брендов** к предсказуемому end-to-end UX:
- куратор понимает «что делать дальше» в очереди и карточке заявки;
- владелец канала видит изменения (статус/назначение/заметки/шаблонные ответы);
- бренд получает понятный ответ (шаблоны), без утечек контактов;
- навигация Back/Menu/Home и return-to (ret) не создают ощущения «вернуло не туда».

## Что проверено

1) `🧹 Кабинет куратора` → `📨 Очередь заявок` (aggregate across workspaces):
- статусы `🆕/💬/✅/⛔` и фильтры `📋 Все / 👤 Мои / 🆓 Свободные`;
- быстрые кнопки открытия заявки;
- footer: Back to `a:cur_home` + Menu/Home.

2) Куратор внутри канала: `a:cur_ws` → `📨 Inbox брендов` (`a:ws_leads|ret:cw`).

3) Карточка заявки (`a:lead_view`) в роли куратора:
- доступные действия: шаблоны ✅/🧾/❌, статус `💬 В работу/✅ Закрыть`, назначение `👤 Взять себе`, заметки.
- отсутствие “кликабельных” контактов/URL (plain UI) в кураторском просмотре.

4) Доставка шаблонов бренду (`sendLeadTemplateReply`) и side-effects:
- запись в thread, audit trail, auto-assign, auto-status transitions.

## Найдено и исправлено (STEP278)

### 1) Нет явного «что дальше» в очереди заявок и карточке (UX)
Добавлены короткие подсказки «Что дальше»:
- в `renderCuratorInbox` (очередь по всем каналам);
- в `renderWsLeadsList` (если актор — куратор);
- в `renderLeadView` (если актор — куратор).

### 2) Потеря фильтра назначения при возврате из карточки в очередь
Раньше `a:lead_view` из `a:cur_inbox` не сохранял `af` и возвращал на дефолт.
Сделано:
- в кнопках открытия заявки добавлено `|af:${af}`;
- Back теперь возвращает в `a:cur_inbox|...|af:${af}`.

### 3) Уточнение подтверждения отправки
`answerCallbackQuery` после отправки шаблона теперь сообщает конкретно: `✅ Отправлено бренду`.

## Smoke checklist (ручная проверка)

Куратор:
1) `🧹 Кабинет куратора` → `📨 Очередь заявок` → переключить фильтр `📋/👤/🆓`.
2) Открыть заявку из списка → Back возвращает в очередь **с тем же фильтром**.
3) В карточке заявки:
   - нажать `👤 Взять себе` → появится отметка назначения;
   - отправить шаблон `✅/🧾/❌` → toast `✅ Отправлено бренду`;
   - поставить `💬 В работу` / `✅ Закрыть` → статус обновлён.

Владелец:
4) Открыть ту же заявку из `📨 Заявки брендов` → видит заметки/статус/назначение.

Риск регрессий: **низкий** (copy + callback_data параметр `af`; бизнес-логика не менялась).
