# 14 — Brand Leads: brand-side “What next” signals (reverse side) — 2026-03

Цель:
- Закрыть цикл по Brand Leads «в обратную сторону»: когда владелец/куратор **ответил** или **вручную сменил статус** заявки → бренд получает сообщение и понимает следующий шаг.
- Без расширения поверхности действий: используем уже существующие кнопки (`💬 Диалог`, `🪟 Витрина`, `🔓 Контакты`, навигация).
- Без подсказок обхода unlock/контактов: в тексте нет инструкций “как достать контакт бесплатно”, только безопасная навигация внутри бота.

## Что поменялось

### 1) Ответ креатора/куратора → бренд
В сообщениях бренду (шаблонный ответ и ручной ответ) добавлен блок:
- **«Что дальше»**: `💬 Диалог → ✍️ Ответить` (продолжить переписку) и `🪟 Витрина` (посмотреть профиль).

Это делает сообщение самодостаточным: бренд понимает, где отвечать и как вернуться к треду.

### 2) Вручную изменили статус lead → бренд
Раньше при ручной смене статуса (в карточке заявки) бренд **не получал** отдельного сигнала.
Теперь: если статус реально изменился (`from → to`), бренд получает сообщение:
- «Статус заявки обновлён» + `from → to`
- **«Что дальше»**: открыть `💬 Диалог` и написать уточнение или открыть `🪟 Витрина`.

Анти‑спам:
- уведомление отправляется **только** при реальном изменении статуса.

## QA (ручной smoke)
1) Бренд: открыть диалог по lead → видеть кнопки `💬 Диалог` / `✍️ Ответить`.
2) Владелец/куратор: отправить ответ (шаблон) → бренд получает сообщение с блоком «Что дальше».
3) Владелец: ответить вручную → бренд получает сообщение с блоком «Что дальше».
4) Куратор/владелец: вручную сменить статус заявки (например `new → in_progress` или `in_progress → closed`) → бренд получает «Статус обновлён» + «Что дальше».

Риск регрессий: **низкий** (только текст и дополнительная отправка уведомления в статус‑хендлере; hot UI пути не затронуты).
