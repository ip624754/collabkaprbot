# 16 — Brand Leads E2E smoke (brand ↔ team ↔ curator) — 2026-03-03

Цель: быстрый end‑to‑end smoke по Brand Leads, чтобы убедиться, что:
- бренд ↔ команда ↔ куратор получают понятные сигналы;
- везде есть «Что дальше» (самодостаточность),
- нет подсказок обхода unlock/контактов,
- возвраты после ручных ответов не тупиковые.

> Это smoke‑сценарий. Он не добавляет новых действий и не требует изменения БД.

---

## Предусловия
- Есть бренд‑workspace (владелец) и хотя бы один куратор.
- У куратора есть доступ к «🧹 Кабинет куратора» и «📨 Очередь заявок».
- В боте включены стандартные уведомления (не отключены глобально).

---

## Сценарий A — Новая заявка → куратор взял → ответ → бренд ответил
1) **Бренд** создаёт заявку (lead) к креатору.
   - Ожидаем: владельцу/кураторам приходит уведомление о новой заявке.
   - Проверить: есть блок **«Что дальше»** (Открыть/Шаблоны/Ответить).

2) **Куратор** открывает `📨 Очередь заявок` → открывает заявку → жмёт `👤 Взять себе`.
   - Ожидаем: владельцу приходит уведомление «взята в работу».
   - Проверить: есть **«Что дальше»**, без лишних кнопок.

3) **Куратор** отправляет ответ через `⚡ Шаблоны` (любой шаблон).
   - Ожидаем: владельцу приходит уведомление со сниппетом + (если статус поменялся) строка `Статус: from → to`.
   - Проверить: есть **«Что дальше»**.

4) **Бренд** получает ответ.
   - Проверить: есть **«Что дальше»**: `💬 Диалог → ✍️ Ответить` и `🪟 Витрина`.

5) **Бренд** открывает `💬 Диалог` → жмёт `✍️ Ответить` → отправляет текст.
   - Ожидаем: бренд получает квитанцию «✅ Отправлено…» + блок **«Что дальше»**.
   - Проверить: есть кнопка `💬 Диалог`, и текст не подталкивает к контактам.

6) **Команда/куратор** получает уведомление о сообщении бренда.
   - Проверить: есть блок **«Что дальше»** (Открыть/Ответить).

---

## Сценарий B — Ручной ответ владельца (return-to-card)
1) **Владелец** открывает lead → `✍️ Ответить` → отправляет текст.
   - Ожидаем: после отправки UI **возвращает в карточку заявки** (не отдельная «квитанция»).
   - Проверить: в карточке видны актуальные кнопки и можно продолжить действия.

2) **Бренд** получает сообщение.
   - Проверить: есть блок **«Что дальше»** (Диалог/Ответить/Витрина).

---

## Сценарий C — Ручная смена статуса (сигнал бренду)
1) **Куратор или владелец** меняет статус lead вручную (например `new → in_progress` или `in_progress → closed`).
   - Ожидаем: владельцу/кураторам приходит уведомление (только если статус реально изменился).
   - Ожидаем: **бренд получает** сообщение «Статус обновлён: from → to» + **«Что дальше»**.

2) Проверить анти‑спам:
   - если повторно нажать тот же статус (без изменения) — бренд **не** должен получать уведомление.

---

## Негатив‑проверки (обязательно)
- Ни в одном сообщении нет подсказок «скиньте телефон/почту», «напишите напрямую», «ссылка в профиле».
- В «Что дальше» пункты соответствуют **реальным label** кнопок.
- Никаких новых действий/кнопок не появилось.
